# 图表

在表格视图中使用柱状图、条形图、折线图、环形图和数值卡片呈现记录。

国际化版本需要插件 API **3.7.0**，支持 **Eidos Lite 0.29.0** 或 **Eidos CLI 3.3.0** 及以上版本。旧宿主会拒绝安装新归档；已有旧版安装仍可使用。

在插件管理器安装并启用后，从表格的视图菜单添加图表。在视图设置中选择分组字段、数值字段、计算方式、日期分组、排序和图例。已有配置值和字段 ID 保持不变；切换语言不会清空配置或筛选条件。

图表跟随宿主当前的查询与筛选，优先使用宿主聚合，也支持本地批量读取回退。支持计数、求和、平均值、最小值和最大值，以及按日、月、年分组。Chart.js 和样式包含在归档内，离线可用。

PNG 导出通过宿主的文件导出能力完成；Lite 显示系统保存对话框，支持该能力的 CLI Serve 触发浏览器下载。没有导出能力时会说明限制；错误与取消状态在界面中显示。图表只读，不申请文件系统权限。仪表盘中使用紧凑的嵌入式呈现。

## 开发

使用 Node.js 22.12 及以上版本和 SDK/tools 0.9.0，运行 `npm ci`、`npm test`、`npm run check -- --target lite` 和 `npm run pack:plugin`。使用 CLI 时另行检查 `--target cli`。许可为 MIT。
